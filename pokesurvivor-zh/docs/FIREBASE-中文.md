# 沿用 PokéSurvivor 原作者的線上服務

中文版目前沿用原作者已設定好的線上服務，不用建立或提供自己的 Firebase 專案。遊戲會連到原作者的 Firebase 專案 `pokesurvivor-free`，以及原作者的 TURN 服務 `turn.pokesurvivor.com`。

## 可用功能

在原作者服務持續可用、帳號建立未被限制的前提下，可使用：

- 註冊、登入與跨裝置雲端存檔
- 搜尋玩家、加好友、好友在線狀態與房間邀請
- 最多 4 人合作（WebRTC；網路無法直連時會嘗試原作者 TURN 中繼）
- 排行榜與成績檢舉

中文版的程式已恢復原作者 Firebase 設定與 TURN 網址，不需要編輯 Firebase 設定或部署 Firebase 規則。遊戲必須透過 HTTP/HTTPS 網址開啟，不能用 `file://` 雙擊 HTML。

## 重要：資料與登入憑證會交給原作者服務

- 帳號驗證、玩家名稱、雲端存檔、好友關係、房間訊號與排行榜資料會存放或處理在**原作者管理**的 Firebase 專案，不是你的私人資料庫。原作者可能管理、移除或停止該服務；中文版無法保證其可用性或資料保留。
- 使用合作模式時，遊戲會把 Firebase 登入 ID token 傳給 `https://turn.pokesurvivor.com/`，由它核發短期 TURN 連線憑證。這是原版合作中繼的設計；請只在你接受將登入憑證提供給該服務的情況下使用。
- 不要把這個服務當成私有或機密的資料庫；不要在遊戲裡使用與重要私人帳號相同的密碼。
- 本專案不是 PokéSurvivor 原作者營運或支援的中文版。線上服務是否接受中文版的玩家與流量，需以原作者實際設定為準。

## 登入方式與網址限制

- **名稱＋密碼登入**：一般不受網域限制（尚未在原作者服務上實測）。
- **Google 登入**：原作者的 Firebase 只授權 `localhost`、`pokesurvivor.com`、`www.pokesurvivor.com`、`jpter78.github.io` 等網域。必須用 **`http://localhost:埠號`** 開啟；用 `127.0.0.1` 或區網 IP（例如 `http://192.168.x.x:3000`）都會顯示「這個網域尚未在 Firebase 授權」。

## 朋友如何連線

朋友必須開啟同一個可從其裝置連到的遊戲網址。若只在區網內玩，可用伺服器電腦的區網 IP（此時請用名稱＋密碼登入，不要用 Google）。Firebase 只提供帳號、存檔、好友與連線協調，不會替你託管這份中文版遊戲檔案。
